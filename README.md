### About

I'm a web designer and Discord bot developer. My work pairs a considered front-end with a backend that has to survive production — ELO engines, OAuth2, scheduled jobs, Docker deploys and the self-hosted services I run myself.

- Currently building out my [portfolio](https://kashcmdd.github.io/portfolio/): architecture diagrams and decision logs now ship as static pages.
- Most of what I write is TypeScript, Python and C#, with a bias toward small, single-purpose tools.

### Discord bots & self-hosted

- **Nebula** — a reproducible, scripted [Red-DiscordBot](https://github.com/Cog-Creators/Red-DiscordBot) deployment: pinned environment, deterministic cog list, backups and crash supervision. Built to be rebuilt from scratch.
- **Vibe** — a DeepSeek-powered Discord bot that behaves like a server member, driving ~117 tools (moderation, channels, roles, tickets, levels, scheduled posts) behind a passive anti-scam watchdog. *Reworked from the [upstream fork](https://github.com/lizereride90/vibe-bot) into a SQLite-backed build.*
- **discord-bot-cogs** — original Red cogs, including a DeepSeek AI assistant with permission-checked server tools.
- **Melon** — a maintained fork of the all-in-one Melon multipurpose bot (antinuke, automod, tickets, giveaways). *[Fork](https://github.com/kashcmdd/Melon-All-In-One-Discord-Bot) of AeroX Development's project.*
- **Homelab** — self-hosted services and bots running on a personal VPS behind Docker.
